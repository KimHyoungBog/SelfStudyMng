# Spec — 중학생 학습관리 앱 — 2026-07-29

> `/plan` 슬래시 커맨드로 작성. 사용자 sign-off 후 확정.

## 목표 (1문장)
중학교 1학년 학생이 사전 등록된 일일 학습 스케줄을 기준으로 매일 완료 여부와 실제 공부 시간을 직접 기록하고, 주간 달성 현황을 확인할 수 있다.

## 배경 / 맥락
중학교 1학년은 과목이 많아지고 자기주도 학습이 처음 요구되는 시기다. 부모 개입 없이 아들 스스로 오늘 할 공부를 확인하고 체크하는 습관을 만들기 위한 도구가 필요하다.

## In Scope
- 과목 등록: 과목명, 요일별 목표 학습 시간(분) 설정·편집·삭제
- 오늘의 학습 화면: 당일 스케줄 목록, 항목별 완료 체크 + 실제 시간 입력
- 주간 요약 화면: 이번 주 과목별 목표 시간 vs 실제 시간 비교
- 주간 요약 화면: 이전/다음 주 이동 및 "이번 주로" 복귀 — 과거 학습 기록 조회 (2026-07-30 추가)
- 데이터 localStorage 저장 (새로고침 후 유지)
- PC 우선, 모바일 반응형 (breakpoint 768px)

## Out of Scope
- 서버/DB, 로그인/인증
- 알림·리마인더
- 부모 확인/관리 기능
- 숙제 마감일 관리, 시험 일정 관리
- 월별·연간 통계
- 공부 타이머 (시간 직접 입력으로 단순화)
- 다국어 (한국어 고정)

## 사용자 / 시나리오
- 누가: 중학교 1학년 남학생
- 언제: 공부 시작 전(오늘 스케줄 확인) + 과목 완료 후(체크 + 시간 입력) + 주말(주간 요약 확인)
- 어디서: PC 브라우저 주, 스마트폰 보조

## 완료 조건
- [x] 과목을 추가·편집·삭제할 수 있다 (과목명 + 요일별 목표 시간)
- [x] 오늘의 학습 화면에 당일 요일에 등록된 과목 목록이 표시된다
- [x] 각 과목에 완료 체크와 실제 공부 시간(분)을 입력할 수 있다
- [x] 입력 데이터가 localStorage에 저장되어 새로고침 후에도 유지된다
- [x] 주간 요약 화면에서 과목별 목표 시간 합계 vs 실제 시간 합계를 볼 수 있다
- [x] PC·모바일 뷰 모두 정상 표시된다
- [x] 주간 요약 화면에서 이전 주로 이동해 과거 학습 기록을 조회할 수 있다
- [x] 현재 주를 넘어 미래 주로는 이동할 수 없다

## 테스트 케이스
1. **정상**: 수학 등록(월~금 30분) → 월요일 오늘 화면에 수학 30분 표시 → 완료 체크 + 실제 40분 입력 → 주간 요약에서 수학 목표 30분 / 실제 40분 표시
2. **에지 (해당 요일 스케줄 없음)**: 토요일 접속, 등록 과목 없음 → "오늘 예정된 학습이 없습니다" 표시
3. **에지 (시간 미입력)**: 완료 체크만 하고 시간 미입력 → 실제 시간 0분으로 처리, 주간 요약에 0분 반영
4. **에지 (과목 미등록)**: 과목 없는 상태에서 오늘 화면 → "과목을 먼저 등록하세요" 안내 + 설정 화면 링크

## 하드 임계값
- **성능**: 체크·입력 반응 < 200ms
- **품질**: TypeScript 타입 에러 0건, 린트 에러 0건
- **커버리지**: Playwright E2E — 정상 시나리오(케이스 1) 통과

## 비기능 요구
- **보안**: 입력값 XSS — React 기본 이스케이프로 충족
- **접근성**: 버튼·입력 요소 label 명시, 기본 키보드 탐색
- **i18n**: 한국어 고정
- **모바일**: 반응형, 768px breakpoint

## 명시된 가정
- 단독 사용자 1명 — 로그인 불필요
- 스케줄은 처음 한 번 설정 후 필요 시 수정
- localStorage 초기화 시 데이터 소실은 감수 가능
- **(2026-07-30 추가)** 과거 주 조회 시 "목표 시간"은 그 시점의 값이 아니라 **현재 등록된 과목 설정 기준**으로 계산됨 (목표 시간에 시점 스냅샷 없음). 이후 과목의 요일별 목표를 수정하면 과거 주 조회 화면의 목표/달성률도 함께 바뀜 — 의도적 단순화, `/evaluate` 결함 #1(major)로 식별 후 이번 스코프에서는 데이터 모델 확장 대신 가정으로 명문화
- **(2026-07-30 추가)** 과목을 삭제하면 해당 과목의 과거 학습 기록(`DailyRecord`)도 함께 영구 삭제됨 — soft-delete 미지원. 과거 기록 조회 기능과는 별개로 기존부터 존재하던 동작이며 유지하기로 함 (`/evaluate` 결함 #2·minor)
